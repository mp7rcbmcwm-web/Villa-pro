SINAV YILDIZIM AI — iPhone/Safari API anahtarı düzeltmesi

YAYINLAMA
1. ZIP dosyasını aç.
2. İçindeki tüm dosyaları aynı yayın klasörüne yükle.
3. index.html dosyasını eski sürümün üzerine yaz.
4. Uygulamayı HTTPS adresinden Safari ile aç ve sayfayı yenile.

API ANAHTARI
- Ayarlar > Yapay zekâ özel öğretmen bölümünden anahtarı gir.
- “Anahtarı bu cihaza kaydet” düğmesine bas.
- Ekrandaki durum mesajını kontrol et.
- Kalıcı depolama mümkün değilse uygulama geçici oturum depolamasını kullanır ve bunu açıkça bildirir.
- API anahtarı JSON yedek dosyasına eklenmez.
- Anahtarı paylaşma veya ortak kullanılan cihazlarda saklama.

NOT
Kod kontrolü yapılmıştır; gerçek iPhone üzerinde uçtan uca test yapılmamıştır. Kamera/OCR, mikrofon ve Gemini bağlantısını cihazda ayrıca test et.
